# 2026-04-26 侧轮廓视角还原、背景图片缩放锚点与右键禁用

## 提交信息
- **分支**: `master`
- **改动文件**: `src/components/ThreeScene.vue`

---

## 一、改动背景

在 2026-04-20「滑条增量旋转与预设视角修复」第 8 节中，主三维窗口的 `_perpAD`（宽度方向向量）被取反以适配 A→D 视角。本次需要：

1. 将 `_perpAD` 恢复为原始 D→A 方向（移除 `.negate()`）
2. 背景图片缩放滑条范围改为 0.5~2.0
3. 背景图片缩放锚点从图片中心改为 Z 轴与图片平面的交点
4. 禁止右键拖拽图片

---

## 二、核心改动

### 1. `_perpAD` 恢复 D→A 方向

**文件**: `ThreeScene.vue` `generateCustomBezierCurves()`

**改动**: 移除 `.negate()`，恢复为原始方向
```ts
// 改前
const _perpAD = _zHat.clone().cross(AD.clone().normalize()).negate(); // 视角从A看D
// 改后
const _perpAD = _zHat.clone().cross(AD.clone().normalize()); // 视角从D看A
```

### 2. 图片缩放滑条范围调整

**改动**: `min` 从 `0.1` 改为 `0.5`，`max` 从 `5` 改为 `2.0`

### 3. 图片缩放锚点改为 Z 轴交点

**问题**: 原来缩放以图片自身中心为锚点，用户希望以 Z 轴与图片平面的交点 `(0, 0, planeZ)` 为锚点。

**方案**: 存储 `bgOriginPivot` 基准（平面创建/拖拽后的位置 + 缩放值 + 局部 pivot），在 `imageScale` watch 中用公式直接计算正确位置，避免增量累积漂移：

```ts
// P(s) = basePos + Q * ((baseScale - s) * pivotLocal)
```

**数据结构**:
```ts
let bgOriginPivot: {
  basePos: THREE.Vector3;    // 锚定时的 mesh 位置
  baseScale: number;         // 锚定时的缩放值
  pivotLocal: THREE.Vector3; // 原点投影在平面局部坐标中的 XY 偏移
} | null = null;
```

**触发时机**:
- 背景平面创建时初始化
- 图片拖拽结束后更新（以拖拽后的新位置为基准）

**关键公式推导**:
- 平面位于位置 P，朝向 Q，缩放 s
- Z 轴交点在平面局部坐标: `pivotLocal = invQ * (-P)`, z=0
- 交点世界坐标随缩放变化: `P + Q * (s * pivotLocal)`
- 为保持交点不动: `P(s) = basePos + Q * ((baseScale - s) * pivotLocal)`

### 4. 禁止右键拖拽

**改动**: 在 DragControls 创建后，capture 阶段拦截右键 pointerdown 事件

```ts
renderer.domElement.addEventListener('pointerdown', (e) => {
  if (e.button === 2) e.stopImmediatePropagation();
}, true);
```

## 三、涉及的关键变量

| 变量 | 说明 |
|------|------|
| `bgOriginPivot` | 缩放锚点基准（位置 + 缩放值 + 局部 pivot），供 imageScale watch 使用 |
| `_perpAD` | 宽度方向向量，恢复为不取反的原始方向 |
| `imageScale` | 图片缩放比例，范围 0.5~2.0 |

## 四、遗留说明

1. 切换场景后恢复保存位置时，`bgOriginPivot` 会基于保存位置重新计算，缩放行为应保持一致。
2. 若用户清除 localStorage 后首次加载，平面位置从 `dataCenter + cameraDirection * 50` 初始化，锚点为该位置下的 Z 轴交点。
